3. 오라클 컨테이너 생성하기

3.1 네트워크 생성하기

docker network create network-address

3.2 오라클용 볼륨 생성하기

docker volume rm 볼륨명 <- 볼륨 삭제하기

3.3 오라클 컨테이너 생성하기
docker run -d --name oracle --network network-address -p 1522:1521 -p 5501:5500 -v oracle-data:/opt/oracle/oradata -v ${PWD}/scripts:/container-entrypoint-initdb.d -e ORACLE_PASSWORD=java1234 -e ORACLE_CHARACTERSET=AL32UTF8 -e TZ=Asia/Seoul gvenzl/oracle-xe:18.4.0

도커 컴포즈, Docker Compose
- 여러 개의 컨테이너를 한번에 생성/실행/종료 하는 도구
- 오케스트레이션 이라고 함

도커 컴포즈 설치하기
- 도커와 별개의 프로그램
- 윈도우/macOS -> 도커 데스크탑 설치 -> 도커 엔진 + 도커 컴포즈
- 리눅스 -> 도커 엔진 설치, 도커 컴포즈 설치

도커 컴포즈 설정하기
- address-db -> "docker-compose.yml"

docker-compose.yml 구조

services: # 각각의 컨테이너를 정의 (컨테이너 == 서비스)
  서비스명: # 컨테이너명
  images: # 만들 컨테이너 이미지의 베이스 이미지
  ports: # 포트 포워딩
  volumes: # 스토리지 마운트
  networks: # 네트워크 설정
  environment: # 넘겨줄 환경변수들
  depends_on: # 의존성. 

networks: # 네트워크 정의

volumes: # 볼륨 정의

도커 컴포즈 실행 방법
docker-compose.yml 에서 실행되는 일들

1. 도커 컴포즈 시작
docker-compose up [-d]
    - -d 붙이면 컨테이너가 detached로(백그라운드로) 실행됨
    - 볼륨 생성
    - 네트워크 생성
    - 이미지 생성
    - 컨테이너 생성 및 실행
    을 한방에 해버린것
    
    docker ps -a
    docker network ls
    docker volume ls
    docker image ls
    
    근데 내가 중간에 뭔가 쿼리라던지 수정할게 생김
    그럼 저 위에 과정을 다시 해야함
    그래서 컴포즈 종료 명령어를 씀

2. 도커 컴포즈 종료
docker-compose down [-v]
    - 컨테이너 삭제됨
    - 네트워크 삭제됨
    - 볼륨은 -v 붙여야 삭제됨
    - 이미지는 삭제 안되는데 어차피
    새로 만들면 덮어쓰기 되서 상관없음

3. 도커 컴포즈 중지
docker-compose stop
    - 이미지, 볼륨, 네트워크는 그대로임
    - 컨테이너만 중지함
    
4. 도커 컴포즈 시작
docker-compose start
    - 컨테이너만 다시 시작함
