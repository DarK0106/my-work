JPA, Java Persistence API
- 자바 진영에서 ORM 기술 표준으로 사용되는 인터페이스
- 실제 기술이 아니고 형식을 만들어놓은게 JPA
- ORM(Object-Relational Mapping)

자바(객체) <- (데이터) -> 오라클(테이블)

class Test <- (매핑) -> tblAddress

JDBC 기반 기술
1. MyBatis
    - Mapping Framework
    - 오라클 레코드를 자바 쪽으로 전달하면
    알아서 클래스 객체로 바뀜
    - SqlsessionTemplate에다가
    Dto dto = template.selectOne("sql")만 하면 됐음
    
2. JPA
    - ORM
    - 자바(객체) <-> 오라클(테이블)
    - 모든 DB 데이터를 자바처럼 접근하고 조작할 수 있음
    - ORM은 프로그램도 아니고 기술 이름도 아닌 단지 개념임
    - ORM을 실제로 구현한 기술이 있는데 그게 Hibernate
