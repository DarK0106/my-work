Thymeleaf
- 자바 템플릿 엔진 -> 뷰 페이지를 만드는 기술
- 서버 측에서 동적으로 HTML을 생성하는 기술 -> Server Side Rendering
- 20~30년 동안 JSP가 하던 일이었는데
- JSP는 톰캣에 종속되어있기 때문에
- Spring이 톰캣에서 좀 벗어나고자
- JSP를 버림
- Thymeleaf는 톰캣과는 무관한 기술
- Thymeleaf 외에도 Mustach, Freemaker, Velocity 가 있음
