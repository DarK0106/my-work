1. none: ERD + SQL(DDL) -> JPA + Entity -> Repository 사용

2. create: JPA + Entity -> 애플리케이션(서버) 시작하면 자동으로 엔티티가 DB에 테이블을 생성함 -> Repository 사용
애플리케이션을 재시작할때마다 새로운 테이블을 생성함

3. update: JPA + Entity -> 애플리케이션(서버) 시작하면 자동으로 엔티티가 DB에 테이블을 생성함 -> Repository 사용
애플리케이션을 재시작하면 변경된 엔티티만 DB에 반영함

4. validate: ERD + SQL(DDL) -> JPA + Entity -> Repository 사용
애플리케이션을 재시작하면 실제 DB 테이블과 엔티티를 비교하여 차이가 있는지 검증
차이가 있다면 에러를 띄움
