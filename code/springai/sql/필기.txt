Text to SQL
- 프롬프트를 쿼리로 바꾸기
- 사용자가 질문(=프롬프트)을 하면 LLM이 그걸 SQL로 생성해서
오라클 질의를 통해 결과를 도툴해서 LLM이 최종적으로 응답을 할것임
- 기업에서의 구성원이 다 개발자가 아닐거니까 전산실에다가 의뢰를 하면
개발자한테 전달되는 그 일련의 과정들이 시간이 걸릴거니까
마치 즉석식품 만들듯이 SQL을 만들어서 씀

일반 개발(a) vs AI 개발(b)

1. 쿼리 형태
    a. 개발자가 미리 작성(정적)
    b. AI가 상황에 따라 즉석 생성(동적)
    
2. 결과 형태
    a. 형식이 고정되어있음 -> ResultSet -> DTO, Entity
    b. AI가 무슨 쿼리를 짤지 모르기때문에 MyBatis, JPA 사용 사실상 불가
       그래서 Spring JDBC 에서 Map을 사용
       
3. 결과 구조
    a. DTO, Entity
    b. Map
