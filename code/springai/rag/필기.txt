RAG, Retrieval-Augmented Generation, 검색 증강 생성
- Tool Calling 때와 비슷한 맥락
- LLM이 지식 절단된 마지막 시간이 있을건데
- LLM이 그 이후의 정보는 모름
- 그래서 Tool Calling 을 이용해서 실시간 정보같은걸 가져왔었음
- RAG 를 통해 실시간 정보나 특별한 영역 내의 정보를 얻어올 수 있음
- LLM이 학습하지 못한 여러 가지 자료들을 요청(=프롬프트)할때 같이 전달함
- RAG -> Google NoteBookLM
