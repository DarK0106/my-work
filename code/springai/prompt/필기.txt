LLM
- 단기 기억 상실증
- LLM의 지식 -> 머신 러닝
    - 대량 자료 전달 -> 기반 학습
- LLM -> 프롬프트 질문 -> 이전 질문과 이어지지 않음
    - 그래서 LLM 얘가 이전 대화 계속 보면서 대화하는거임
    - 그래서 질문이 점점 거대해지는거임
    - 그래서 LLM이 알아서 이전 대화를 버림
    - 그래서 예전에 대화했던거 물어보면 기억을 못하는거
    
Chat Client API
- Chat Client 클래스
- AI Model과 통신을 하는 역할
- Fluent API: 자바 스트림 방식 처럼 함수형 프로그래밍 방식을 지원
    ex) 객체.메서드().메서드().메서드()..
    
Chat Client API 처리 흐름
    - 사용자가 질문 -> 프롬프트 구성 -> AI 모델 호출 -> 응답 -> 사용 또는 가공

내부 처리 과정(우리 모르게 일어남):
1. HTTP 요청 만들기
2. Authorization 헤더 넣기(인증과 관련된 부분)
3. JSON Body 만들기
4. model, temperature 설정하기
5. HTTP Request 요청
6. 응답
7. 응답된 데이터를 JSON 으로 리턴함
8. 파싱해서 사용

실제로 우리가 구현한 코드상에서의 처리:
위의 흐름을 단순하게 만든 것임
이게 실행되면 내부적으론 위의 흐름이 발생하는것
1. chatClient.prompt()
    - AI 모델에게 보낼 프롬프트를 생성하겠습니다.(초기화시키는 역할)
    - 위의 흐름 중 1, 2, 4번이 일어남
2. system(message)
    - AI에게 페르소나, 규칙 부여
3. user(message)
    - 사용자의 질문
4. call()
    - AI 모델에게 요청 발생
    - 동기 방식임, AI 모델로부터 답변이 오기 전 까지는 대기할 수 밖에 없음
5. content()
    - AI의 응답에서 최종 답변에서의 문자열만을 반환함
    - AI 응답에는 우리가 흔히 보는 답변만 있는게 아니라
    - 토큰사용량도 보이고 어떤 모델 썼는지도 보이고
    - 종료된 이유(finish reason)도 있고 metadata도 있음
    - 기술적으로 사람이 보지 않아도 되는 데이터들도
    - 포함되어 있는 것임
