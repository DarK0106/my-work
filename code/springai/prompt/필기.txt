LLM
- 단기 기억 상실증
- LLM의 지식 -> 머신 러닝
    - 대량 자료 전달 -> 기반 학습
- LLM -> 프롬프트 질문 -> 이전 질문과 이어지지 않음
    - 그래서 LLM 얘가 이전 대화 계속 보면서 대화하는거임
    - 그래서 질문이 점점 거대해지는거임
    - 그래서 LLM이 알아서 이전 대화를 버림
    - 그래서 예전에 대화했던거 물어보면 기억을 못하는거
