새 Dynamic Web Project
	-"AuthTest" -> "auth", web.xml 체크

웹 보안 구현
- 로그인 / 로그아웃

1. 인증, Authentication
- 로그인(Login), 사인-인(Sign-in)
- 현재 접속자가 해당 사이트의 구성원인지 확인하는 작업
- 아이디와 암호를 통해 본인 확인 작업 -> 인증 티켓 발급

2. 허가, Authorization
- 일부 페이지 -> 인증 받은 사용자 접속이 가능
	- 접근을 했을 때 인증을 받은 사람이라면
		- 너 티켓 있니 라고 물어봄
			- O, 인증된 사용자 -> 통과
			- X, 익명 사용자(티켓이 없으면 그냥 익명이라고 부름) -> 거절
			
라이브러리 설치
- lib 폴더에 ojdbc11.jar, jstl-1.2.jar, lombok.jar

패키지 + 구조 + 파일
- AuthTest -> "script.sql"

com.test.java -> Index.java // 시작 페이지
com.test.java.auth -> Login.java // 로그인(폼)
				   -> LoginOk.java // 로그인(처리)
				   -> LogoutOk.java // 로그아웃(처리)
				   
com.test.java.member -> Member.java // 회원 전용
com.test.java.admin -> Admin.java // 관리자 전용
com.test.java.model -> AuthDao.java
					-> AuthDto.java

webapp -> WEB-INF -> views -> index.jsp
						   -> auth -> login.jsp
						   -> member -> member.jsp
						   -> admin -> admin.jsp
