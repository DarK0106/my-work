에러: There is no PasswordEncoder mapped for the id "null"
PasswordEncoder가 없대요

스프링 시큐리티는 반드시 암호를 암호화(인코딩)해서 저장하도록 함
1111 같은 평문으로는 저장할 수 없음

스프링 시큐리티 4까지는 PasswordEncoder가 선택사항이었는데
스프링 시큐리티 5부터는 PasswordEncoder가 필수가 되었음

잠시 테스트하기 위해 임시로 PasswordEncoder를 사용하지 않도록 {noop} 사용
password="{noop}1111"

8 접근 권한(403) 페이지
- 로그인을 안 한 상태에서 접근 불가능한 URL로 접근 -> 로그인 페이지로 이동
- 로그인을 한 상태에서 접근 불가능한 URL로 접근 -> 403 오류 페이지

8.1. 403 오류가 발생하면 특정 페이지로 이동
접근 제한 오류 페이지
com.test.java.controller -> AuthController
views -> auth -> accesserror.jsp
accesserror.jsp를 403 오류와 연결하기

8.2 AccessDeniedHandler 구현
에러가 나면 내가 하고 싶은 행동을 하고 미리 준비해놨던 페이지를 보여줌
AccessDeniedHandler 사용자 클래스를 선언
위의 클래스는 403 에러 발생 시 추가 업무를 구현할 수 있음
com.test.java.auth -> CustomAccessDeniedHandler.java

9. 커스텀 로그인 페이지 구현
자동 생성 로그인 페이지를 사용하지 않고, 직접 구현한 로그인 페이지 사용
com.test.java.controller -> AuthController.java
view -> auth -> customlogin.jsp

커스텀 로그인 페이지를 구현했으니
security-context 가서 커스텀 로그인 페이지에 연결

다시 로그인 시도 -> 로그인에 실패함 -> 이유: CSRF(Cross-site request forgery)
CSRF, 사이트 간 요청 위조
- 로그인 한 사람 몰래 로그인 한 사람이 마치 의도한 듯 행동(예: 결제)을 하도록 만드는 해킹 기법

9.1 그럼 어떻게함? 개발할때는 CSRF 방지 설정을 잠시 끔

9.2 그러다가 배포/운영 할 때 CSRF 방지 설정을 킴
    - POST 요청 페이지에서 토큰 설정
