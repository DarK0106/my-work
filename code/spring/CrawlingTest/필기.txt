크롤링 할 때 주의점 !!
- 저작권 문제
- 정도껏 해야함 -> 긁어오는 작업이다 보니 서버한테는 좋은 점이 하나도 없음
    -> 크롤링 프로그램은 속도가 빠르고 무제한으로 크롤링을 할 수 있는데,
    -> 서버 입장에서는 이득이 없고 비용이랑 트래픽만 발생해서 좋을 점이 없음
    -> 그래서 대형 사이트 같은 곳은 크롤링 프로그램은 막아둠
